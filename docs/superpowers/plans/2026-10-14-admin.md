# Admin Area Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in `/admin` area where the photographer uploads, edits, moves, features, reorders, and deletes photos and creates, renames, reorders, and deletes categories.

**Architecture:** Supabase Auth session in cookies via `@supabase/ssr`; a Next.js 16 `proxy.ts` refreshes it for `/admin` and `/login`. Server actions act as the signed-in user, and row-level security (an `admins` table + `is_admin()`) decides who may write. Files are shrunk in the browser and uploaded straight to Supabase Storage; metadata goes through server actions.

**Tech Stack:** Next.js 16.4 (App Router, Cache Components, React Compiler), React 19.3, TypeScript, Tailwind CSS v4, `@supabase/supabase-js` 2.x, `@supabase/ssr` 0.12, `@dnd-kit/core` 6 + `@dnd-kit/sortable` 10 + `@dnd-kit/utilities` 3, Vitest 5 + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-14-admin-design.md`

## Global Constraints

- The service-role key is never read by `front/photofolio`; it stays in `supabase/.env`.
- Frontend env vars: `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` (server) and `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (browser; same values).
- Storage bucket: `portfolio-images`. New uploads: `photos/<uuid>.jpg`.
- Resize: longest edge ≤ 2560 px, never upscale, JPEG quality 0.85, EXIF orientation applied. Reject non-images and originals over 50 MB.
- Renaming a category changes `name` only, never `slug`.
- Slugs: lowercase, accents stripped, non-alphanumerics → `-`, trimmed of `-`; empty → `category`; duplicates get `-2`, `-3`, …
- Title from file name: file name without its last extension; empty → `Untitled`.
- Every server action re-checks admin and returns `{ ok: true, … } | { ok: false, error, signedOut? }`; it never throws to the UI.
- With Cache Components, cookie reads must sit inside `<Suspense>` (build error otherwise). Next 16 uses `proxy.ts`, not `middleware.ts`. Do not use `forbidden()` (experimental).
- Visual language: paper `#faf9f7` / ink `#1a1a1a` / muted `#737373` / line `#e0dbd6` tokens (`bg-paper`, `text-ink`, `text-muted`, `border-line`), Cormorant headings, tiny uppercase tracked labels, no rounded corners.
- Public pages, their URLs, and their look do not change.
- Commands run from `front/photofolio` unless stated; tests with `npm test` (`vitest run`). Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **Unsupported image formats (e.g. HEIC from an iPhone)** pass the `image/*` check but can't be decoded → that file fails with "Couldn't read this image. Try a JPEG or PNG." and the rest of the batch continues. Test: Task 8 `uploadPhoto` "shrink failure".
- **Deleting the category currently being viewed** → the admin navigates to `/admin` (first remaining category) instead of showing a dead selection. Test: Task 6 CategoryList "deleting the active category".
- **Session expiring mid-upload** → the failing file's uploaded object is removed (no orphans) and the row shows a "Sign in again" link. Tests: Task 8 `uploadPhoto` "createImage failure removes file" and UploadQueue "signed-out".
- **Two categories with the same name, or a name of only symbols** → unique slug (`-2`) / `category`. Tests: Task 2 slug tests, Task 5 `createCategory`.
- **Moving a photo to another category** → it is appended to the end of the target (not colliding with existing order) and leaves the current grid. Test: Task 5 `updateImage` "move appends"; UI relies on the action's `revalidatePath`.

```ts
export function slugify(name: string): string {
  const slug = name
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
  return slug || 'category';
}

export function uniqueSlug(base: string, taken: string[]): string {
  const used = new Set(taken);
  if (!used.has(base)) return base;
  let n = 2;
  while (used.has(`${base}-${n}`)) n++;
  return `${base}-${n}`;
}
```

```ts
export function fitWithin(width: number, height: number, max = MAX_EDGE) {
  const longest = Math.max(width, height);
  if (longest <= max) return { width, height };
  const scale = max / longest;
  return { width: Math.round(width * scale), height: Math.round(height * scale) };
}
```

```ts
// The id order after dragging activeId onto overId's position.
export function moveId(ids: string[], activeId: string, overId: string): string[] {
  const from = ids.indexOf(activeId);
  const to = ids.indexOf(overId);
  if (from === -1 || to === -1 || from === to) return ids;

  const next = [...ids];
  next.splice(from, 1);
  next.splice(to, 0, activeId);
  return next;
}
```

`src/lib/supabase-server.ts`:

```ts
import 'server-only';
import { cookies } from 'next/headers';
import { createServerClient } from '@supabase/ssr';
import type { SupabaseClient } from '@supabase/supabase-js';
import type { Database } from './database.types';

export type AdminSupabase = SupabaseClient<Database>;

// Acts as the signed-in user, from the auth cookies. Create one per request.
export async function createSupabaseServerClient(): Promise<AdminSupabase> {
  const url = process.env.SUPABASE_URL;
  const key = process.env.SUPABASE_PUBLISHABLE_KEY;

  if (!url || !key) {
    throw new Error('Missing SUPABASE_URL or SUPABASE_PUBLISHABLE_KEY environment variables');
  }

  const cookieStore = await cookies();
  return createServerClient<Database>(url, key, {
    cookies: {
      getAll: () => cookieStore.getAll(),
      setAll(cookiesToSet) {
        try {
          cookiesToSet.forEach(({ name, value, options }) => cookieStore.set(name, value, options));
        } catch {
          // Server Components can't set cookies; proxy.ts refreshes the session instead.
        }
      },
    },
  });
}
```

```ts
import { NextResponse, type NextRequest } from 'next/server';
import { createServerClient } from '@supabase/ssr';

// Refreshes the Supabase auth cookie before admin pages render, so sessions
// don't expire mid-edit. Pattern from the @supabase/ssr docs.
export async function proxy(request: NextRequest) {
  let response = NextResponse.next({ request });

  const url = process.env.SUPABASE_URL;
  const key = process.env.SUPABASE_PUBLISHABLE_KEY;
  if (!url || !key) return response;

  const supabase = createServerClient(url, key, {
    cookies: {
      getAll: () => request.cookies.getAll(),
      setAll(cookiesToSet, headers) {
        cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
        response = NextResponse.next({ request });
        cookiesToSet.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
        Object.entries(headers).forEach(([header, value]) => response.headers.set(header, value));
      },
    },
  });

  await supabase.auth.getClaims();
  return response;
}
```

```ts
import type { AdminSupabase } from '@/lib/supabase-server';

type Result = { data: unknown; error: { message: string } | null };
export type QueryCall = { table: string; op: string; chain: unknown[][] };

// A chainable, awaitable stand-in for supabase-js. Results are queued per
// "<table>.<select|insert|update|delete>", "rpc.<name>", or "storage.<method>";
// anything not queued resolves to { data: null, error: null }.
export function fakeSupabase(results: Record<string, Result[]> = {}) {
  const calls: QueryCall[] = [];
  const storageCalls: { bucket: string; method: string; args: unknown[] }[] = [];
  const rpcCalls: { fn: string; args: unknown }[] = [];
  const take = (key: string): Result => results[key]?.shift() ?? { data: null, error: null };

  function query(table: string) {
    const call: QueryCall = { table, op: '', chain: [] };
    calls.push(call);
    const builder: { [method: string]: unknown } = {};
    for (const method of ['select', 'insert', 'update', 'delete', 'eq', 'order', 'limit', 'maybeSingle', 'single']) {
      builder[method] = (...args: unknown[]) => {
        if (!call.op && ['select', 'insert', 'update', 'delete'].includes(method)) call.op = method;
        call.chain.push([method, ...args]);
        return builder;
      };
    }
    builder.then = (resolve: (r: Result) => unknown, reject?: (e: unknown) => unknown) =>
      Promise.resolve(take(`${table}.${call.op}`)).then(resolve, reject);
    return builder;
  }

  const client = {
    from: query,
    rpc: (fn: string, args?: unknown) => {
      rpcCalls.push({ fn, args });
      return Promise.resolve(take(`rpc.${fn}`));
    },
    storage: {
      from: (bucket: string) => ({
        remove: (paths: string[]) => {
          storageCalls.push({ bucket, method: 'remove', args: [paths] });
          return Promise.resolve(take('storage.remove'));
        },
        getPublicUrl: (path: string) => ({
          data: { publicUrl: `https://example.supabase.co/storage/v1/object/public/${bucket}/${path}` },
        }),
      }),
    },
  };

  return { client: client as unknown as AdminSupabase, calls, storageCalls, rpcCalls };
}
```

```ts
'use server';

import { redirect } from 'next/navigation';
import { revalidatePath } from 'next/cache';
import { requireAdmin } from '@/lib/admin/auth';
import { createSupabaseServerClient, type AdminSupabase } from '@/lib/supabase-server';
import { slugify, uniqueSlug } from '@/lib/admin/slug';
import { IMAGE_BUCKET } from '@/lib/storage';
import { SIGNED_OUT_ERROR, type ActionResult } from '@/lib/admin/types';
import type { Database } from '@/lib/database.types';

class ActionError extends Error {}

// Unwraps a supabase-js result, turning its error into a readable ActionError.
function must<T>(result: { data: T; error: { message: string } | null }, what: string): T {
  if (result.error) throw new ActionError(`Couldn't ${what}: ${result.error.message}`);
  return result.data;
}

async function withAdmin<T extends object>(
  run: (supabase: AdminSupabase) => Promise<ActionResult<T>>
): Promise<ActionResult<T>> {
  const auth = await requireAdmin();
  if (!auth.ok) {
    return auth.reason === 'signed-out'
      ? { ok: false, error: SIGNED_OUT_ERROR, signedOut: true }
      : { ok: false, error: 'This account is not authorized.' };
  }

  try {
    const result = await run(auth.supabase);
    if (result.ok) revalidatePath('/admin');
    return result;
  } catch (error) {
    if (error instanceof ActionError) return { ok: false, error: error.message };
    throw error;
  }
}

async function nextCategoryOrder(supabase: AdminSupabase): Promise<number> {
  const last = must(
    await supabase
      .from('categories')
      .select('display_order')
      .order('display_order', { ascending: false })
      .limit(1)
      .maybeSingle(),
    'load categories'
  );
  return last ? last.display_order + 1 : 0;
}

async function nextImageOrder(supabase: AdminSupabase, categoryId: string): Promise<number> {
  const last = must(
    await supabase
      .from('images')
      .select('display_order')
      .eq('category_id', categoryId)
      .order('display_order', { ascending: false })
      .limit(1)
      .maybeSingle(),
    'load photos'
  );
  return last ? last.display_order + 1 : 0;
}

export async function signOut(): Promise<void> {
  const supabase = await createSupabaseServerClient();
  await supabase.auth.signOut();
  redirect('/login');
}

export async function createCategory(name: string) {
  return withAdmin<{ slug: string }>(async (supabase) => {
    const trimmed = name.trim();
    if (!trimmed) return { ok: false, error: 'Category name is required.' };

    const existing = must(await supabase.from('categories').select('slug'), 'load categories');
    const slug = uniqueSlug(slugify(trimmed), existing.map((category) => category.slug));
    const display_order = await nextCategoryOrder(supabase);

    must(await supabase.from('categories').insert({ name: trimmed, slug, display_order }), 'create the category');
    return { ok: true, slug };
  });
}

export async function renameCategory(id: string, name: string) {
  return withAdmin(async (supabase) => {
    const trimmed = name.trim();
    if (!trimmed) return { ok: false, error: 'Category name is required.' };

    must(await supabase.from('categories').update({ name: trimmed }).eq('id', id), 'rename the category');
    return { ok: true };
  });
```

```ts
'use client';

import { useState } from 'react';
import type { ActionResult } from '@/lib/admin/types';

// A local copy of a server-provided list for optimistic updates. It resets
// whenever the server sends a new list (after an action revalidates).
export function useOptimisticList<T>(serverItems: T[]) {
  const [items, setItems] = useState(serverItems);
  const [source, setSource] = useState(serverItems);

  if (serverItems !== source) {
    setSource(serverItems);
    setItems(serverItems);
  }

  async function update(next: T[], save: () => Promise<ActionResult>): Promise<ActionResult> {
    const previous = items;
    setItems(next);
    const result = await save();
    if (!result.ok) setItems(previous);
    return result;
  }

  return [items, update] as const;
}
```

```tsx
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { DndContext, KeyboardSensor, PointerSensor, closestCenter, useSensor, useSensors, type DragEndEvent } from '@dnd-kit/core';
import { SortableContext, sortableKeyboardCoordinates, verticalListSortingStrategy } from '@dnd-kit/sortable';
import { createCategory, reorderCategories } from '@/app/(admin)/admin/actions';
import { moveId } from '@/lib/admin/reorder';
import type { ActionFailure, AdminCategory } from '@/lib/admin/types';
import CategoryRow from './CategoryRow';
import ErrorNotice from './ErrorNotice';
import { inputClass, labelClass, textButtonClass } from './styles';
import { useOptimisticList } from './useOptimisticList';

type CategoryListProps = {
  categories: AdminCategory[];
  activeSlug: string | null;
};

export default function CategoryList({ categories, activeSlug }: CategoryListProps) {
  const router = useRouter();
  const [items, update] = useOptimisticList(categories);
  const [failure, setFailure] = useState<ActionFailure | null>(null);
  const [newName, setNewName] = useState('');
  const [creating, setCreating] = useState(false);
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 5 } }),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates })
  );

  async function handleDragEnd({ active, over }: DragEndEvent) {
    if (!over || active.id === over.id) return;
    const ids = moveId(items.map((category) => category.id), String(active.id), String(over.id));
    const next = ids.map((id) => items.find((category) => category.id === id)!);
    const result = await update(next, () => reorderCategories(ids));
    setFailure(result.ok ? null : result);
  }

  async function handleCreate(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setCreating(true);
    const result = await createCategory(newName);
    setCreating(false);
    setFailure(result.ok ? null : result);
    if (result.ok) {
      setNewName('');
      router.push(`/admin?category=${result.slug}`);
    }
  }

  function handleDeleted(category: AdminCategory) {
    if (category.slug === activeSlug) router.push('/admin');
  }

  return (
    <aside className="flex flex-col gap-6">
      <h2 className="text-[10px] uppercase tracking-[0.2em] text-muted">Categories</h2>

      <DndContext sensors={sensors} collisionDetection={closestCenter} onDragEnd={handleDragEnd}>
        <SortableContext items={items.map((category) => category.id)} strategy={verticalListSortingStrategy}>
          <ul className="border-t border-line">
            {items.map((category) => (
              <CategoryRow
                key={category.id}
                category={category}
                active={category.slug === activeSlug}
                onError={setFailure}
                onDeleted={handleDeleted}
              />
            ))}
          </ul>
        </SortableContext>
      </DndContext>

      <form onSubmit={handleCreate} className="flex flex-col gap-2">
        <label htmlFor="new-category" className={labelClass}>New category</label>
        <div className="flex gap-2">
          <input
            id="new-category"
            value={newName}
            onChange={(event) => setNewName(event.target.value)}
            required
            disabled={creating}
            className={inputClass}
          />
          <button type="submit" disabled={creating} className={textButtonClass}>Add</button>
        </div>
      </form>

      <ErrorNotice failure={failure} />
    </aside>
  );
}
```

```tsx
'use client';

import { useState } from 'react';
import { DndContext, KeyboardSensor, PointerSensor, closestCenter, useSensor, useSensors, type DragEndEvent } from '@dnd-kit/core';
import { SortableContext, rectSortingStrategy, sortableKeyboardCoordinates } from '@dnd-kit/sortable';
import { reorderImages, setFeatured } from '@/app/(admin)/admin/actions';
import { moveId } from '@/lib/admin/reorder';
import type { ActionFailure, AdminCategory, AdminImage } from '@/lib/admin/types';
import EditPanel from './EditPanel';
import ErrorNotice from './ErrorNotice';
import PhotoCard from './PhotoCard';
import { useOptimisticList } from './useOptimisticList';

type PhotoManagerProps = {
  category: AdminCategory;
  categories: AdminCategory[];
  images: AdminImage[];
};

export default function PhotoManager({ category, categories, images }: PhotoManagerProps) {
  const [items, update] = useOptimisticList(images);
  const [failure, setFailure] = useState<ActionFailure | null>(null);
  const [editingId, setEditingId] = useState<string | null>(null);
  const editing = items.find((image) => image.id === editingId) ?? null;
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 5 } }),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates })
  );

  async function handleDragEnd({ active, over }: DragEndEvent) {
    if (!over || active.id === over.id) return;
    const ids = moveId(items.map((image) => image.id), String(active.id), String(over.id));
    const next = ids.map((id) => items.find((image) => image.id === id)!);
    const result = await update(next, () => reorderImages(ids));
    setFailure(result.ok ? null : result);
  }

  async function toggleFeatured(target: AdminImage) {
    const next = items.map((image) => (image.id === target.id ? { ...image, isFeatured: !image.isFeatured } : image));
    const result = await update(next, () => setFeatured(target.id, !target.isFeatured));
    setFailure(result.ok ? null : result);
  }

  return (
    <section className="flex min-w-0 flex-col gap-6">
      <h1 className="text-3xl leading-tight">{category.name}</h1>

      <ErrorNotice failure={failure} />

      {items.length === 0 ? (
        <p className="text-muted">No photos in this category yet.</p>
      ) : (
        <DndContext sensors={sensors} collisionDetection={closestCenter} onDragEnd={handleDragEnd}>
          <SortableContext items={items.map((image) => image.id)} strategy={rectSortingStrategy}>
            <ul className="grid grid-cols-2 gap-4 sm:grid-cols-3 lg:grid-cols-5">
              {items.map((image) => (
                <PhotoCard
                  key={image.id}
                  image={image}
                  onEdit={() => setEditingId(image.id)}
                  onToggleFeatured={() => toggleFeatured(image)}
                />
              ))}
            </ul>
          </SortableContext>
        </DndContext>
      )}

      {editing && <EditPanel key={editing.id} image={editing} categories={categories} onClose={() => setEditingId(null)} />}
    </section>
  );
}
```

```ts
import { fitWithin } from './resize';

const JPEG_QUALITY = 0.85;

// Browser-only: decodes the file (applying EXIF rotation), scales it to fit
// within the max edge, and re-encodes it as JPEG.
export async function shrinkImage(file: File): Promise<{ blob: Blob; width: number; height: number }> {
  const bitmap = await createImageBitmap(file, { imageOrientation: 'from-image' });
  try {
    const { width, height } = fitWithin(bitmap.width, bitmap.height);
    const canvas = document.createElement('canvas');
    canvas.width = width;
    canvas.height = height;

    const context = canvas.getContext('2d');
    if (!context) throw new Error('Canvas is not supported in this browser.');
    // JPEG has no transparency; paint transparent PNG areas white instead of black.
    context.fillStyle = '#ffffff';
    context.fillRect(0, 0, width, height);
    context.drawImage(bitmap, 0, 0, width, height);

    const blob = await new Promise<Blob | null>((resolve) => canvas.toBlob(resolve, 'image/jpeg', JPEG_QUALITY));
    if (!blob) throw new Error('Could not encode the image.');
    return { blob, width, height };
  } finally {
    bitmap.close();
  }
}
```

```ts
import { createImage } from '@/app/(admin)/admin/actions';
import { createSupabaseBrowserClient } from '@/lib/supabase-browser';
import { IMAGE_BUCKET } from '@/lib/storage';
import { shrinkImage } from './shrinkImage';
import { titleFromFilename } from './titleFromFilename';
import type { ActionResult } from './types';

export const MAX_UPLOAD_BYTES = 50 * 1024 * 1024;

export type UploadStatus = 'resizing' | 'uploading' | 'saving' | 'done' | 'failed';

export function validateFile(file: File): string | null {
  if (!file.type.startsWith('image/')) return 'Not an image file.';
  if (file.size > MAX_UPLOAD_BYTES) return 'File is larger than 50 MB.';
  return null;
}

export async function uploadPhoto(
  file: File,
  categoryId: string,
  onStatus: (status: UploadStatus) => void
): Promise<ActionResult> {
  onStatus('resizing');
  let shrunk: Awaited<ReturnType<typeof shrinkImage>>;
  try {
    shrunk = await shrinkImage(file);
  } catch {
    return { ok: false, error: "Couldn't read this image. Try a JPEG or PNG." };
  }

  onStatus('uploading');
  const storagePath = `photos/${crypto.randomUUID()}.jpg`;
  const storage = createSupabaseBrowserClient().storage.from(IMAGE_BUCKET);
  const { error: uploadError } = await storage.upload(storagePath, shrunk.blob, { contentType: 'image/jpeg' });
  if (uploadError) return { ok: false, error: `Upload failed: ${uploadError.message}` };

  onStatus('saving');
  const result = await createImage({
    categoryId,
    storagePath,
    title: titleFromFilename(file.name),
    width: shrunk.width,
    height: shrunk.height,
  });
  // Never leave a stored file without a row pointing at it.
  if (!result.ok) await storage.remove([storagePath]);
  return result;
}
```

```tsx
import { useState } from 'react';
import { uploadPhoto, validateFile, type UploadStatus } from '@/lib/admin/uploadPhoto';
import type { ActionFailure } from '@/lib/admin/types';
import ErrorNotice from './ErrorNotice';
import { textButtonClass } from './styles';

type QueueItem = {
  id: string;
  file: File;
  status: UploadStatus;
  failure?: ActionFailure;
  retryable: boolean;
};

const STATUS_LABEL: Record<UploadStatus, string> = {
  resizing: 'Resizing…',
  uploading: 'Uploading…',
  saving: 'Saving…',
  done: 'Done',
  failed: 'Failed',
};

export default function UploadQueue({ categoryId }: { categoryId: string }) {
  const [items, setItems] = useState<QueueItem[]>([]);
  const [dragOver, setDragOver] = useState(false);

  function patch(id: string, changes: Partial<QueueItem>) {
    setItems((current) => current.map((item) => (item.id === id ? { ...item, ...changes } : item)));
  }

  async function run(item: QueueItem) {
    const result = await uploadPhoto(item.file, categoryId, (status) => patch(item.id, { status, failure: undefined }));
    patch(item.id, result.ok ? { status: 'done' } : { status: 'failed', failure: result, retryable: true });
  }

  async function addFiles(fileList: FileList | File[]) {
    const added: QueueItem[] = Array.from(fileList).map((file) => {
      const invalid = validateFile(file);
      return {
        id: crypto.randomUUID(),
        file,
        status: invalid ? 'failed' : 'resizing',
        failure: invalid ? { ok: false, error: invalid } : undefined,
        retryable: false,
      };
    });
    setItems((current) => [...current, ...added]);

    // One at a time keeps memory and bandwidth predictable for big batches.
    for (const item of added) {
      if (item.status !== 'failed') await run(item);
    }
  }

  const hasFinished = items.some((item) => item.status === 'done' || item.status === 'failed');

  return (
    <div className="flex flex-col gap-3">
      <label
        onDragOver={(event) => {
          event.preventDefault();
          setDragOver(true);
        }}
        onDragLeave={() => setDragOver(false)}
        onDrop={(event) => {
          event.preventDefault();
          setDragOver(false);
          addFiles(event.dataTransfer.files);
        }}
        className={`flex cursor-pointer flex-col items-center gap-1 border border-dashed px-6 py-8 text-center transition-colors ${
          dragOver ? 'border-ink bg-white/60' : 'border-line hover:border-muted'
        }`}
      >
        <span className="text-[10px] uppercase tracking-[0.18em]">+ Add photos</span>
        <span className="text-xs text-muted">Choose files or drop them here. They&apos;re resized before uploading.</span>
        <input
          type="file"
          accept="image/*"
          multiple
          aria-label="Add photos"
          className="sr-only"
          onChange={(event) => {
            if (event.target.files) addFiles(event.target.files);
            event.target.value = '';
          }}
        />
      </label>

      {items.length > 0 && (
        <ul className="flex flex-col divide-y divide-line border-y border-line text-xs">
          {items.map((item) => (
            <li key={item.id} className="flex flex-wrap items-center gap-x-4 gap-y-1 py-2">
              <span className="min-w-0 flex-1 truncate">{item.file.name}</span>
              {item.status === 'failed' && item.failure ? (
                <ErrorNotice failure={item.failure} />
              ) : (
                <span className={item.status === 'done' ? 'text-ink' : 'text-muted'}>{STATUS_LABEL[item.status]}</span>
              )}
              {item.status === 'failed' && item.retryable && (
                <button type="button" onClick={() => run(item)} className={textButtonClass}>Retry</button>
              )}
            </li>
          ))}
        </ul>
      )}

      {hasFinished && (
        <button
          type="button"
          onClick={() => setItems((current) => current.filter((item) => item.status !== 'done' && item.status !== 'failed'))}
          className={`${textButtonClass} self-start`}
        >
          Clear finished
        </button>
      )}
    </div>
  );
}
```

```ts
import 'server-only';
import type { AdminSupabase } from '@/lib/supabase-server';
import { IMAGE_BUCKET } from '@/lib/storage';
import type { AdminCategory, AdminImage } from './types';

export async function getAdminData(
  supabase: AdminSupabase,
  requestedSlug?: string
): Promise<{ categories: AdminCategory[]; activeCategory: AdminCategory | null; images: AdminImage[] }> {
  const { data: categoryRows, error } = await supabase
    .from('categories')
    .select('id, slug, name, display_order, images(count)')
    .order('display_order', { ascending: true });
  if (error) throw new Error(`Failed to load categories: ${error.message}`);

  const categories: AdminCategory[] = categoryRows.map((row) => ({
    id: row.id,
    slug: row.slug,
    name: row.name,
    displayOrder: row.display_order,
    photoCount: row.images[0]?.count ?? 0,
  }));

  const activeCategory = categories.find((category) => category.slug === requestedSlug) ?? categories[0] ?? null;
  if (!activeCategory) return { categories, activeCategory, images: [] };

  const { data: imageRows, error: imagesError } = await supabase
    .from('images')
    .select('*')
    .eq('category_id', activeCategory.id)
    .order('display_order', { ascending: true });
  if (imagesError) throw new Error(`Failed to load photos: ${imagesError.message}`);

  const images: AdminImage[] = imageRows.map((row) => ({
    id: row.id,
    categoryId: row.category_id,
    storagePath: row.storage_path,
    title: row.title,
    description: row.description,
    displayOrder: row.display_order,
    isFeatured: row.is_featured,
    width: row.width,
    height: row.height,
    url: supabase.storage.from(IMAGE_BUCKET).getPublicUrl(row.storage_path).data.publicUrl,
  }));

  return { categories, activeCategory, images };
}
```
